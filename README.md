# Arduino GPIO LED Control — Wokwi

My first hands-on Embedded C hardware simulation project using Wokwi.

## Project

This project demonstrates basic GPIO output control by making an LED blink using an Arduino Uno simulation.

## Concepts Learned

- GPIO
- Digital output
- HIGH and LOW states
- LED control
- Timing and delays
- Basic Embedded C programming

## Implementation

The LED is configured as a digital output.

The program:

1. Sets the LED pin as OUTPUT
2. Sets the pin HIGH
3. Waits 1 second
4. Sets the pin LOW
5. Waits 200 ms
6. Repeats continuously
